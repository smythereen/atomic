# atomic

Header-only atomic primitives (`atomic_32.h`, `cmpxchg.h`, `atomic_bump.h`) used by sys and other units.

**Requires the base repository** to be installed first (project root with
`BASE`, `rules.mak`, `targets.mak`, and the `repo` unit). Clone base,
then fetch this unit with `repo add atomic` or via the project starter list.
